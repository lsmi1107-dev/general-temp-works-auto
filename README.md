# 공통가설공사_자동내역
2026-10-08 최종 구현분 (Lovable v3 -> v4 업그레이드)

## 구현 내용
- 2-Step 구조
  - 1단계: 연면적 기준 가견적 IF(<=200,6, <=1000,30, <=3000,63, <=6000,76, 130)
  - 2단계: 표준품셈 2-1-2 직접노무비 기준 면적표
- LINE ITEM 분리: 감독자용/도급자용/창고 동일 공식이지만 별도 ITEM
- 컨테이너 자동 혼합배치: 18㎡(3x6) + 27㎡(3x9) 최적 조합 자동 계산
- 설치형: 추후 구현 (준비중 표시, 임대형만 활성화)

## 표준품셈 2-1-2 표
- 0-1.5억: 30/30/27
- 1.5-3억: 40/50/30
- 3-9억: 50/70/40
- 9-30억: 70/90/50
- 30-90억: 100/140/70
- 90-150억: 140/210/80
- 150-300억: 180/300/90
- 300-500억: 190/330/95
- 500억이상: 210/360/100
